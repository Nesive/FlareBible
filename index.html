译本

译本说明：和合本、KJV、吕振中、文理和合本、ASV、WEB、YLT、Darby、日内瓦圣经、BBE、路德圣经 1912、Segond 1910、Reina-Valera 1909、Almeida ARC、Statenvertaling 1637 均为公有领域；当代译本为 Biblica 开放资源（CC BY-SA 4.0）；ESV 由 Crossway 官方 API 实时提供，需在设置里填入免费密钥，本站不存储 ESV 全文。微读圣经另有新译本、和合本 2010 等版权译本，本站未收录。

阅读设置

翻页：仿微读圣经，左右滑动或点页面两边翻页，键盘 ← → 也可翻页；章末继续翻进入下一章。

打开后每节下方显示原文逐词（旧约希伯来文、新约希腊文），点任意词查看 Strong's 编号、中文释义与全部出处。原文按 KJV 节号对齐，与和合本节号在少数章节有漂移（如民数记第 1 章）。

句末出处例：这样人们就知道我是耶和华（以西结书 28:20 和合本）。复制格式对单节与多节复制都生效。

书签、高亮、笔记与阅读记录保存在本机浏览器。导出备份为 JSON 文件，可在换设备或清数据后导入恢复。

档案

每个档案的高亮、书签、笔记与阅读记录各自独立，点档案名切换，切换后页面会重新加载。主题、字号等显示设置所有档案共用。导出备份只导出当前档案的数据。

ESV 密钥免费获取：到 api.esv.org 注册账号并创建 API 应用，密钥只保存在本机浏览器，不上传。填入后即可在线阅读 ESV。
